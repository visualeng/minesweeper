# 💣 Сапер на Python

Классический сапер 9×9 с 10 минами. На встроенном модуле `turtle`, ничего доустанавливать не надо.

## Запуск

```bash
python minesweeper.py
```

## Управление

| Действие | Кнопка |
|---|---|
| Открыть клетку | **ЛКМ** |
| Поставить/снять флаг | **ПКМ** |
| Новая игра | **R** (работает и в русской раскладке: **к**) |
| Выход | **Esc** |

## Возможности

- Первый клик всегда безопасен — мины ставятся **после** него
- Флуд-филл: пустая клетка открывает всю область вокруг
- Счётчик оставшихся мин
- Цветные цифры как в виндовс-сапере
- При победе непомеченные мины закрашиваются автоматически
- При поражении видно все мины и отмечены неправильные флаги

## Как это работает

- Каждая клетка — отдельная черепаха `turtle`, клики ловятся через `onclick`
- Мины — `set` координат, поиск мин вокруг — обход 8 соседей
- Открытие пустых клеток — стек (обход в ширину)
- Первый клик защищён: его клетка и соседи исключаются из установки мин

## Что учил на этом проекте

- `write()` в `turtle` **не принимает `fill`** — цвет текста = цвет черепахи, поэтому текст клетки красится отдельным `pencolor`
- Кириллицу в `onkeypress` забиндить нельзя (tk ругается на keysym) — русскую раскладку ловим общим обработчиком `KeyPress`
- Лямбда в цикле без захвата координат замыкается на последней клетке — поэтому `cx=x, cy=y` в параметрах по умолчанию
