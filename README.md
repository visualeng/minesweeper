# 💣 Сапер на Python

Классический сапер с выбором поля: от 8×8 до 128×128 и любым числом мин. Окно и холст даёт встроенный модуль `turtle`, ничего доустанавливать не надо.

## Запуск

```bash
python minesweeper.py
```

## Меню

| Действие | Кнопка |
|---|---|
| Выбрать поле (8×8, 16×16, 32×32, 64×64, 128×128) | клик по кнопке, цифры **1–5**, стрелки **← →** |
| Сколько мин | кнопки **−** / **+**, стрелки **↑ ↓** (показаны число и процент) |
| Начать игру | кнопка **Играть** или **Enter** |
| Выход | **Esc** |

Мин по умолчанию ~15% от клеток (как у виндовса). Поставить можно от 1 до «клеток минус 9» — эти девять уходят под безопасный первый клик. Размер клетки подбирается под экран, поэтому 128×128 спокойно влезает в окно.

## Управление в игре

| Действие | Кнопка |
|---|---|
| Открыть клетку | **ЛКМ** |
| Поставить/снять флаг | **ПКМ** |
| Новая игра | **R** (работает и в русской раскладке: **к**) |
| Назад в меню | **Esc** |

## Возможности

- Размер поля и число мин выбираются до старта, поле можно менять прямо из игры (Esc → меню)
- Первый клик всегда безопасен — мины ставятся **после** него
- Флуд-филл: пустая клетка открывает всю область вокруг, но **останавливается на цифрах**
- Счётчик оставшихся мин в шапке
- Клетки картинками: закрытые серые с фаской, раскрытые плоские с сеткой, цифры стандартными цветами
- При победе непомеченные мины закрашиваются автоматически
- При поражении видно все мины и отмечены неправильные флаги

## Как это работает

- Клетки — картинки на холсте `turtle`-окна (`create_image`), клик ловится один раз на холсте, координата курсора переводится в клетку через `canvasx/canvasy`
- Мины — `set` координат, поиск мин вокруг — обход 8 соседей
- Открытие пустых клеток — стек (обход в ширину)
- Первый клик защищён: его клетка и соседи исключаются из установки мин
- Тайлы рисует `build_tiles.py` (Pillow, без чужих картинок), под размер клетки их ужимает сам Tk через `PhotoImage.subsample`
- Меню — те же примитивы холста с общими тегами: на весь набор кнопки (прямоугольник, фаска, надпись) вешается один тег, и клик срабатывает в любом месте

## Что учил на этом проекте

- **Черепахи не тянут большие поля.** Замер (`bench.py` против `bench_canvas.py`): 16384 клетки-черепахи = 2.3 с на создание и **секунда на каждый перерисовку** (turtle перебирает всех черепах), а те же клетки картинками на холсте — 0.09 с на создание и 0.02 с на клик. Поэтому 128×128 рисуем картинками, а не черепашками
- `screen.cv` у `turtle` — не сам холст, а `Frame`: свои методы он пробрасывает на вложенный `Canvas` (поэтому `bind` и `tag_bind` работают), а фокус ставит `listen()` через `focus_force` — без этого клавиши не приходят
- Кириллицу в `onkeypress` забиндить нельзя (tk ругается на keysym) — русскую раскладку ловим общим обработчиком `KeyPress` и сравниваем `event.char` с «к»
- Картинки 48 px удобно ужимать через `subsample`, но только нацело — поэтому размеры клеток взяты из делителей 48 (48/24/16/12/8/6/4), Pillow на стороне игры не нужна
- Лямбда в цикле без захвата замыкается на последней итерации — поэтому в меню тег кнопки передаётся через параметр по умолчанию (`lambda event, t=tag: ...`)
- Заливка, которая раскидывает соседей **безусловно**, пролетает всё поле за один клик — распространяться можно только из пустых клеток (`n == 0`)
- Оформление «как у всех» делается проще всего: берёшь палитру и фаску из оригинала, а не придумываешь градиенты — выглядит сразу знакомо
- Скриншот через `CopyFromScreen` **врёт**: обычное окно цвета `#c0c0c0` снимается как (224, 229, 240) с розовым отливом — по кадрам проверяй геометрию, но не цвета
